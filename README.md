# 下班後，我用 AI 做的三件事｜磊山社團課簡報

2026-11-27 磊山社團課用的 HTML 簡報，38 張。不用裝任何東西，Chrome 打開就能播。

## 打開

- **上台播放**：用 Chrome 打開 `index.html`。F 全螢幕，→／空白鍵往下，← 退回，N 看講者備註，M 關掉動畫。
- **編輯**：同一個網址後面加 `?edit`，例如 `file:///你的路徑/index.html?edit`。請用 Chrome；Safari 只能下載一份，存不回原檔。

## 編輯器怎麼用

- 點一下選取，雙擊（或 Enter）改字，拖曳移動，拉四個角放大縮小，方向鍵微調。
- 右邊欄：改字體、字級、顏色、對齊、進場動畫。沒選東西時，改這一頁的背景、換頁效果和講者備註。
- 選一張圖按「換一張圖片」，或直接把圖片檔拖到圖上。
- 上方工具列：復原、重做、複製這一頁、刪除這一頁、存檔、下載一份、▶ 播放。左邊縮圖點一下換頁。
- ⌘S 存檔：第一次會問資料夾，選這個資料夾，之後直接存回 `index.html`。
- ⌘Z 復原，⇧⌘Z 重做，▶ 或 ⌘Enter 播放，播放中按 E 回到編輯。

## 兩個人一起改

1. 開始前：`git pull`，然後**重新整理瀏覽器**（沒重新整理就存檔，會蓋掉剛拉下來的版本）。
2. 先講好誰改哪幾頁，只改自己那幾頁，改完 ⌘S。
3. 改完一段就推：`git add -A && git commit -m "改了什麼" && git push`。

- 打開時跳出「恢復草稿」：不確定是不是自己剛剛沒存的，就按不要。
- 存檔時說「檔案被改過」：先按「下載一份」留著，再重新整理拿新版。
- 兩個人改到同一頁，git 會說衝突，交給 Claude 或 Codex 合起來。

## 請不要動

- 「」裡的話都是真實對話原文，不改字。可以整句刪，或換一句別的原文。
- `assets/deck-editor.js` 是編輯器本體。
- 宙黑體字型照 SIL OFL 1.1 授權使用，`assets/fonts/OFL-LICENSE.md` 要留著。
